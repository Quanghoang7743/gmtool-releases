# GMTool — Bộ cài và cập nhật

[Tải phiên bản mới nhất](https://github.com/Quanghoang7743/gmtool-releases/releases/latest)

Kho này lưu bộ cài Windows, thông tin phiên bản `latest.yml` và checksum. Không lưu mã nguồn dự án hay dữ liệu người dùng.

## Windows

Cài GMTool 1.0.30 một lần để bổ sung bộ cập nhật. Đợi các công việc hoàn tất, đóng GMTool rồi cài vào thư mục hiện tại; không cần gỡ bản cũ.

Từ các lần sau: **Thiết lập → Cập nhật GMTool → Tải bản mới → Cài và mở lại**. Ứng dụng tự kiểm tra khi mở, hiển thị tiến độ tải, kiểm tra SHA-512 và yêu cầu hoàn tất công việc trước khi cài. Dữ liệu, model, cấu hình và thư mục video được giữ lại.

Chức năng cài cập nhật trực tiếp ở bản này dành cho Windows x64.
