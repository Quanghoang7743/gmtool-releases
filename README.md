# GMTool — Bộ cài và cập nhật

[Tải phiên bản mới nhất](https://github.com/Quanghoang7743/gmtool-releases/releases/latest)

Kho này lưu bộ cài Windows, thông tin phiên bản `latest.yml` và checksum. Không lưu mã nguồn dự án hay dữ liệu người dùng.

## Windows

Đợi các công việc hoàn tất, đóng GMTool rồi cài bộ cài mới nhất vào thư mục hiện tại; không cần gỡ bản cũ.

**Nếu đang dùng 1.0.30 và trang Thiết lập bị trắng:** tải bộ cài mới nhất từ Releases và cài đè để sửa. Lỗi này đã được sửa từ 1.0.31.

Các lần sau: **Thiết lập → Cập nhật GMTool → Tải bản mới → Cài và mở lại**. Ứng dụng tự kiểm tra khi mở, hiển thị tiến độ tải, kiểm tra SHA-512 và yêu cầu hoàn tất công việc trước khi cài. Dữ liệu, model, cấu hình và thư mục video được giữ lại.

Chức năng cài cập nhật trực tiếp hiện dành cho Windows x64.
